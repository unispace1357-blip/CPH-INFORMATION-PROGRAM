# CPH 2차 UI/UX 개선 (2026-10-25)

## 범위
1. 고객용 호텔 기본 정보 옆 독립 검색창 추가. 기존 주변 시설 검색과 상태를 분리함.
2. 4개 언어의 호텔 안내 원문(문단 순서 및 검수 상태)을 수정하지 않고, 전체 호텔 안내·객실 참고사항을 키워드 검색함. 다른 언어의 동의어도 검색 인덱스로 사용할 수 있으나 화면에는 현재 선택 언어의 문구만 표시함.
3. 검색 결과에 실제 일치 문장을 보여주고 클릭 시 호텔 주제 및 해당 문단으로 이동함. 결과 없음 안내와 검색어 지우기 제공.
4. 객실 이용 12개 문단에 번호·다국어 제목·구분 카드 적용. 제목은 UI 표시 전용이며 호텔 공지 원문은 그대로 유지함.
5. 주변 시설에서 실제 공개 시설이 없는 카테고리는 표시하지 않음. 별도 공식 자료가 있는 '교통' 및 '관광'은 계속 제공. '호텔 관련 시설'은 실제 호텔 내 부대시설 카테고리를 뜻하며, 운영·공개가 확인되지 않은 시설은 임의 등록하지 않음.
6. 고객 모바일 중심으로 검색·시설 카드·객실 번호 안내·상세정보의 간격, 대비, 반응형 레이아웃을 정리함. 직원/관리자 기능, 요청사항, QR 링크는 유지함.

## 검수
- 검색은 메모리 내 로컬 JSON을 사용함. 외부 API 호출, 데이터 수집, 유료 서비스 없음.
- EN/KO/zh-CN/JA: 12개 객실 제목 수 및 기본 키워드와 조식 요금 검색 검사.
- 브라우저에서 검색 결과 클릭/번호 안내/빈 카테고리 제거/기존 고객·직원·관리자 기능과 네이버 경로 회귀 검사.
- QR 주소 및 마지막 검수 날짜는 변경하지 않음. 공개 사이트는 계속 DEMO이며 프로덕션 검증 게이트는 유지함.
