# 송도 관광 개념도 — 독자 제작 및 사용 범위

## 목적

호텔이 고객에게 배포하는 기존 관광 지도를 웹에 다시 게시하지 않고, 별도의 **원본 SVG 개념도**를 프로그램 내에 표시한다. 스마트폰에서 관광지 위치 관계를 살피고, 명소를 누르면 4개 언어로 상세 설명을 볼 수 있다.

## 제작 및 출처

- 지도 배경의 색·수로와 녹지 형태·마커·배치는 새로 작성한 SVG/CSS이며 기존 송도컨벤시아 관광 지도의 디자인·사진·아이콘·문구를 복제하지 않는다.
- 지도 타일·외부 지도 이미지·캡처·유료 API를 사용하지 않는다. 별도 서버가 필요하지 않다.
- 6개 관광지와 호텔 1곳의 위치 참고 좌표는 공개 OpenStreetMap 기반 장소 기록에서 가져온 근사 기준점이다.
- **© OpenStreetMap contributors (ODbL)** 표시를 지도 바로 아래 4개 언어로 제공한다. 지도 베이스맵 전체를 재생산하지 않는다.
- 좌표 배치는 개략적인 상대 위치를 위해서만 사용하며, 도로망·출입구·경로 거리·소요 시간을 나타내지 않는다.
- **네이버 지도는 실제 이동용으로 분리:** 기존에 사용자가 길찾기 검수한 센트럴파크와 G타워는 호텔 출발 경로를 재사용. 나머지 트라이볼·한옥마을·해돋이공원·미추홀공원은 *장소 검색*만 제공하고 경로를 꾸며내지 않는다.

## 이용 및 접근성

- 번호가 표시된 지도 마커 6개와 목록 버튼 6개는 동일한 선택 상태를 공유한다.
- 마커 및 목록은 키보드로 접근 가능하고 `aria-pressed`로 상태를 알린다.
- 선택한 장소의 소개와 네이버 지도 연결은 별도의 영역에서 바로 확인할 수 있다.
- 호텔의 H 마커는 도식상 강조 표기일 뿐 실제 출입구 좌표가 아니다.
- 상단에 **실제 경로/거리용 지도가 아니라는 경고**, 하단에 최신 운영시간·입장 변경 가능성·OSM 출처를 표기한다.
- 4개 언어에서 내용, 경고 및 링크 명칭을 일관되게 제공한다.

## 2026-10-19 마커·언어 선택 바 레이아웃 보정

- 관광지 1(센트럴파크)·2(트라이볼)·3(G타워)의 **기준 위경도·장소 이름·링크는 변경하지 않는다**.
- 겹치는 마커만 CSS 변수(화면표시용 픽셀 오프셋)로 분리한다. 599px 이하의 모바일 화면에는 작은 별도 오프셋을 사용한다.
- 모바일에서도 마커 중심 간격을 확보하도록 실제 화면의 위치 사각형을 320/390/768/1280px에서 확인한다.
- 고객 언어 선택 도구를 `position: static`으로 문서 흐름에 유지해 스크롤해도 관광 지도·상세 설명을 덮지 않는다.
- 브라우저 QA에서 마커 중첩과 언어 도구 겹침을 검사한다. 정식 운영 배포는 여전히 금지한다.
