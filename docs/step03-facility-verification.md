## 현장 담당자 체크리스트

- [ ] CU: 기존 네이버 길찾기 URL이 올바른 CU A동 1층 109호에 도착하는지 확인하고 정상/오류 회신
- [ ] 현대프리미엄아울렛: 출발=송도센트럴파크호텔 → 도착=송도국제대로 123 실제 출입구, 도보 경로 URL 공유
- [ ] G타워: 출발=호텔 → 도착=아트센터대로 175 G타워 1층 출입구, 도보 경로 URL 공유
- [ ] 수상택시: 출발=호텔 → 도착=웨스트보트하우스 인천타워대로 253-34, 도보 경로 URL 공유. 이스트보트하우스 금지

각 URL은 PC/휴대전화에서 실제 지도에 열리는지 확인. 네이버 지도 장소/검색 URL과 길찾기 공유 URL을 혼동하지 않는다.
현장 확인까지 신규 3건의 naverMapUrl, walkingMinutes 및 lastVerifiedAt은 null로 유지한다.
