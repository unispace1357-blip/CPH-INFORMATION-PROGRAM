# 직원 전용 요청사항 — 접수 연결 가이드

## 구조 및 범위

- GitHub Pages 직원용 `#/staff` 페이지의 우측 상단 **요청사항** 버튼에서 입력합니다. 고객용 `#/guest`에는 요청 UI가 없습니다.
- 요청 유형: 정보 추가/정보 수정/오류 신고/기능 개선. 관련 화면: 호텔 업무 영어 응대/주변 시설 안내/기타. 요청 내용: 10~1,000자.
- 개인 고객 이름·연락처·객실 번호 등 개인정보를 **입력하지 않도록** 명시합니다. 직원 신원, IP, 검색기록을 수집하거나 별도 API를 호출하지 않습니다.
- 사용자 입력값은 저장하지 않으며 복사 버튼으로 클립보드에 복사할 수 있습니다. **복사 = 접수 완료가 아닙니다.**
- Google Forms 제출은 Google Forms 사이트에서 사용자가 최종 **제출**을 눌러야 완료됩니다. 접수 데이터를 Google Sheets에서 확인하고 처리는 별도의 GitHub/Codex 개발 작업으로 진행합니다.

## 시트 준비

관리자 확인용 시트 이름은 **CPH 직원 요청사항 관리**입니다. 열: 접수 일시, 요청 유형, 관련 화면, 요청 내용, 처리 상태, 처리 메모. 처리 상태의 드롭다운: 접수/검토 중/완료/보류. Forms가 연결되면 응답 전용 새 탭이 자동 생성됩니다. 필요할 때 검토 대상 요청을 요청 관리 탭에 옮겨 상태를 기록합니다.

## Google Forms 설정 (계정 소유자가 1회 수행)

1. Google Forms에서 **CPH 직원 요청사항** 새 양식을 만듭니다. 단일 필수 질문 **요청 내용**을 **장문형**으로 만듭니다. 그 외 개인정보 수집 질문은 만들지 않습니다.
2. 응답 설정에서 회사 내부 직원 정책에 맞춰 제출 가능 계정 또는 응답자 범위를 제한합니다. 공개 직원용 URL에는 별도 인증이 없으므로 이 제한은 중요합니다.
3. **응답 → 스프레드시트에 연결 → 기존 스프레드시트 선택**을 선택해 `CPH 직원 요청사항 관리` 시트를 연결합니다. 이미 만들어진 요청 관리 탭은 그대로 둡니다.
4. 양식 오른쪽 위 **더보기 → 미리 입력된 링크 가져오기**에서 장문 질문의 응답을 정확히 `CPH_REQUEST_CONTENT_MARKER`로 입력하고 **링크 가져오기**를 선택합니다.
5. 해당 사전입력 **응답자 링크**(편집 링크 아님)를 개발 담당자에게 제공하고 `src/config/staffRequestForm.ts`의 `STAFF_REQUEST_PREFILL_URL`에 넣은 뒤 다시 빌드·배포합니다. 게시 가능한 HTTPS `docs.google.com/forms/d/.../viewform?entry.숫자=CPH_REQUEST_CONTENT_MARKER` 형식만 허용합니다.
6. 직원용에서 내용을 입력해 **Google Forms에서 접수하기**를 누르면 선택 유형·관련 화면·본문이 하나의 장문 질문에 자동 입력됩니다. 사용자는 Forms 페이지에서 **제출**을 누릅니다. 관리자 시트의 응답 탭에 새 행이 생기는지 테스트합니다.

> 주의: CPH는 Google Forms 링크에 입력값을 사전입력해 새 탭으로 여는 방식입니다. Google Forms의 최종 제출을 대리하지 않으며 Sheets에 직접 쓰지도 않습니다. CPH 페이지에 Google OAuth 토큰·시트 편집 링크·비밀번호를 넣지 마세요.

## 운영

- Sheets에서 접수 요청을 확인하고 처리 상태와 처리 메모를 관리합니다. 사용자 응답 기록은 자동으로 삭제·수정하지 않습니다.
- 사용자에게 정보 수정이 자동 게시된다고 알리지 않습니다. 별도 코드 검수 후 GitHub Pages 공개 **DEMO**만 배포합니다.
- 고객용 QR 화면, 호텔 원고, 시설 JSON, 프로덕션 배포 게이트는 변경하지 않습니다.
