## 3. 영어·중국어·일본어 및 직원 영어 응대 교정

- 송쭈집 알쌈은 문어 자체의 알로 오해될 수 있는 *octopus roe-wrap / 鱼卵包小章鱼 / イイダコの卵包み*를 삭제하고, 날치알을 곁들이는 식사라는 뜻으로 3개 언어를 교정.
- 영어 레스토랑/카페 14건의 기계적 `Menu examples include:`를 실제 영어 문장에 자연스럽게 연결하고, 불확실한 판매 여부는 `availability may vary`로 설명.
- 모든 26개 시설의 영어 상호를 라틴 문자로 읽을 수 있도록 수정하되 한국어 원명을 괄호에 보존해 네이버 지도 확인용 이름을 잃지 않도록 함. 원어 공식 영어 상호 인증을 의미하지 않음.
- 외국어 주소 72개 필드에서 한글 도로 이름을 로마자 표기(예: Incheon Tower-daero, Central-ro)로 보완. 건물 동/호 숫자는 유지.
- 금연 규정·20만 원 청소비 및 프론트 앞 선반 배달 수령이 4언어 호텔 정책과 직원 즉시 응대 문구에 일치하는지 자동 검증.
- 영어 발음은 직원 참고용(원문 복사 미포함)이며 원어민 수준 교정이나 음성 인식 검증까지 완료했다는 뜻이 아님.
- 중국어·일본어 상호에는 일부 한국어 고유명사가 남아 있어 **현장 언어 감수 필요**. 메뉴 번역 역시 전문 번역인증 전 초안.

## 5. 실제 Chromium E2E 및 데이터·배포 검사

전용 `scripts/final-qa-ui.cjs`와 격리된 `.github/workflows/final-browser-qa.yml`을 추가하고 다음을 자동 검사:

- 직원 30개 호텔 업무 문장·금연 우선·주차 분리·배달 안내·영어 복사의 원문 무결성.
- 26개 시설 상호, 직원 검색(맥주·현프아·수상택시·김밥 등)과 14개 음식 메뉴 카드 및 복사.
- 고객 4언어 전환에서 26개 상호와 14개 메뉴 설명 일치, 검색·상세 열기/닫기, 객실 안내, 금연 문구, 배달 수령.
- 320·390·768·1280px에서 가로 오버플로 없음, 브라우저 오류 없음. 모바일/PC 스크린샷 수집 및 주요 화면 직접 시각 검수.
- 웨스트보트하우스 도보 네이버 경로, G타워 도보, 아울렛 대중교통 링크의 사용자 지정 출발·도착 POI ID 검증, 외부 지도 실요청은 차단.
- 관리자 26개 시설 표시, HTML/TypeScript/JSON 구조 검증·단위 회귀 테스트·린트·웹/관리자 빌드.
- **DEMO 공개 테스트 빌드 성공**, **정식 production 빌드 의도대로 실패**, 관리자 소스는 공개 번들 제외.

구현상 한계: Playwright 기반 데스크톱 Chromium의 반응형 폭 검사이지, 실기기 iOS Safari·Android Chrome·Mac Safari·Firefox 전수 QA 및 실제 네이버지도 길찾기 경로 서버 검증은 아니다. 화면 캡처는 GitHub Actions artifact에 남김.
