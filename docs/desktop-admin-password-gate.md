# Windows 직원용 프로그램 안의 관리자 비밀번호 창

> 2026-10-26 — 로컬 Windows 실행 프로그램용 기능. GitHub Pages 공개 웹은 관리자 암호 인증 및 편집을 제공하지 않습니다.

## 사용 방법

1. GitHub Actions **Public test web and Windows portable**의 **Windows portable** 아티팩트를 내려받아 압축을 모두 해제합니다. 프로그램(`CPH-Front-Desk.exe`)을 실행합니다.
2. 직원용 첫 화면 상단 또는 좌측 사이드바에서 **관리자 화면**을 누릅니다.
3. **최초 1회** 이 Windows 사용자 계정의 관리자 비밀번호를 설정합니다. 12~128자, 문자와 숫자 포함. 설정 후 동일 비밀번호를 다시 입력해 관리자 창을 엽니다.
4. 이후에는 관리자 화면을 열 때마다 비밀번호를 요청합니다. 5회 연속 실패하면 약 **15분간** 접근이 잠깁니다.
5. 잠금 해제 후에는 별도 **CPH ADMIN MANAGER** 창이 열립니다. 기존 **시설·호텔 정보·타임스페이스 음식점·JSON 가져오기/내보내기·검증** 기능이 동일하게 제공됩니다.
6. 편집 내용은 브라우저 작업 메모리에만 남고 자동으로 공개 사이트에 적용되지 않습니다. 필요한 JSON 파일을 다운로드하고 GitHub 반영과 배포 검수를 거쳐야 합니다.
7. **관리자 창 닫기 · 직원 화면 복귀**를 누르거나 창을 닫으면 해당 편집창에 대한 접근이 종료됩니다.

## 보안 경계

- 암호는 Electron **메인 프로세스**에서 scrypt(N=32768, r=8, p=1), 무작위 salt 및 일정 시간 비교로 확인합니다. 평문 비밀번호는 프로그램 번들이나 로컬 JSON 파일에 기록하지 않습니다.
- 설정 파일은 현재 Windows 사용자의 Electron `userData/admin-auth.json`에 저장합니다. 파일 생성은 기존 파일 덮어쓰기를 차단하고, 오류가 있으면 잠금을 해제하지 않습니다.
- 관리자 인터페이스는 Electron 패키지 내부 별도 폴더로 포함되며 **일반 직원용 GitHub Pages** 번들에는 관리자 편집 컴포넌트가 포함되지 않습니다.
- 일반 직원 화면 렌더러에는 파일 시스템 접근이나 Node.js 실행 권한을 주지 않습니다. 제한된 IPC 메서드로만 인증을 요청합니다.
- 관리자 편집창이 열려 있는 동안에만 특수 로컬 관리자 프로토콜(`cph-admin://`)이 동작합니다. 일반 직원 UI에 관리자 라우터를 추가하지 않습니다.
- 주의: **이것은 사용자 PC 안에서 동작하는 암호 잠금**입니다. 같은 Windows 사용자 계정의 파일을 읽고 삭제·교체할 수 있는 사람, PC 관리자 권한을 가진 사람, 또는 실행 파일을 변조할 수 있는 사람을 상대로 완전한 보안 격리를 보장하지 않습니다. 첫 실행 전에 본인이 비밀번호를 설정하고 Windows 계정의 접근 권한을 별도로 제한해야 합니다.
- 다른 컴퓨터/Windows 사용자 계정으로 로그인하면 비밀번호가 **동기화되지 않습니다.** Windows 계정이나 관리자 프로그램 복사본을 다른 사람이 쓰게 되는 경우 별도 기기에서도 최초 비밀번호를 설정할 수 있으므로, **진짜 본인만 모든 기기에서 로그인**을 보장하려면 인터넷 인증 서버와 계정 인증·권한관리·서버 측 데이터 저장이 필요합니다.

## GitHub Pages와 원격 로그인

GitHub Pages는 정적 호스팅으로 로그인 검증 서버를 제공하지 않습니다. 직원용 공개 웹에서 **관리자 화면**을 선택하면 'Windows 프로그램에서만 가능'이라는 안내만 나타납니다. **비밀번호 입력창은 웹에 노출되지 않습니다.**

나중에 PC/휴대폰 공용 로그인으로 확장하려면, 신뢰 가능한 인증 서비스(Vercel/Cloudflare 등)를 연결하고 서버 측 암호 확인·세션·접근통제·변경 저장/승인 처리를 도입해야 합니다. 현재 연결된 Vercel 팀/프로젝트가 확인되지 않아 웹 관리자용 보안 서버는 구축하거나 배포하지 않았습니다.

## QA

- `scripts/desktop-admin-auth.test.ts`: 비밀번호 강도·무작위 scrypt 해시·로그인 실패 잠금·잘못된 파일 처리 및 공개 번들 격리 검사.
- `scripts/final-qa-ui.cjs`: 일반 웹 직원 화면에서 관리자 버튼·안내창이 작동하되 관리자 비밀번호를 받거나 비공개 화면을 제공하지 않는지 확인.
- `npm run desktop:package`: Windows/Electron 실행 파일에 관리자 번들·안전한 preload·해시 검증 코드가 정상 포함되는지 검증.
- 실제 Windows PC에서 최초 설정·관리자 창 열기·비밀번호 5회 제한 및 JSON 다운로드 테스트는 추가로 현장 확인하는 것이 좋습니다.
