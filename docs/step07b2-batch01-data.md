고유 상호의 공식 외국어 표기는 자료에 없어 확인 완료로 표시하지 않습니다. 한국어 상호를 모든 언어에서 보존하고 영어·중국어·일본어에는 시설 유형을 덧붙여 초안으로 작성했습니다. 새 공식 영문/중문/일문 상호를 만들지 않았습니다. 주소의 도로명과 드림시티 건물명도 지도 대조를 위해 한국어 원문을 보존하고 시·구·동/층/호 표기를 언어별로 정리했습니다.

## 미확인 정보와 출처 불일치

- 5개 모두 실제 도보시간·호텔 출발 경로·길찾기 공유 URL·시설별 정확한 확인 날짜 없음: walkingMinutes/naverMapUrl/lastVerifiedAt null, directions 4개 언어 빈 문자열.
- E열은 거리 조사 그룹·동일 건물 맥락이며 실제 길찾기 문장이 아니므로 이동 안내로 바꾸지 않았습니다. 출처의 H열 도보분도 5개 모두 비어 있습니다.
- 휴무일은 C04의 G10 '연중 무휴'만 반영했습니다. C01의 24시간 표기는 휴무 없음의 근거로 삼지 않았고 C01/C02/C03/C16 closedDays는 4개 언어 모두 빈 문자열입니다.
- C01의 '제3자 표기, 재확인' 단서를 보존합니다. C16의 일요일·공휴일 휴무 및 토요일 휴게시간 적용 여부를 새로 확정하지 않았습니다.
- C16 원본 J22는 센트럴원약국/센트럴로232를 검색하는 URL입니다. 실제 데이터는 사용자가 확인한 채움약국/인천타워대로197번길16 2층240호를 유지합니다. 잘못된 출처 링크만 이 문서와 추출 기준에 기록하고 다른 약국으로 교체하지 않았습니다.
- 기존 출처 URL은 위치 정보/검색/채용 등 자료입니다. 호텔 출발 네이버 길찾기 링크로 변환하지 않았습니다. 지도 미등록 목록: C01·C04·C03·C02·C16 전부.

## 검수와 공개 차단

최종 필수 명령 결과: validate PASS, validate:hotel-copy PASS, test PASS(기존 296 + 신규 25 = **321개**, 실패/스킵 0), lint PASS, build PASS, admin:build PASS. 각 최종 명령은 1회 실행했으며 모두 종료 코드 0입니다. 운영 빌드 보호 관련 기존 자동 테스트도 통과했습니다. 실제 운영 빌드·배포를 성공했다고 보고하지 않습니다.

개발 중 관련 단위 173개와 엄격한 데이터 타입 검사를 실행했습니다. Batch 01 신규 테스트 25개는 원본 6개 객체의 SHA-256·11개 총수·ID 고유성·한국어 원문·다국어 주소 숫자/시각·비공개 정책·Admin 검색/편집/Import/Export·공개 스냅샷 제외·호텔 원고 유지를 확인합니다.

실제 Chromium 1280px에서 5개 시설의 Admin 검색/선택·4개 언어 7개 안내 필드·비공개/미확인 상태를 확인했습니다. 실제 원본 JSON 다운로드/재불러오기/재다운로드의 전체 값이 일치합니다. 영업시간과 가상 URL을 브라우저 메모리에서만 편집·등록·삭제한 후 원래 값으로 복구하고 다운로드가 원본과 같은지 확인했습니다. Staff 및 Guest(4개 언어)의 실제 공개 목록/검색에 5개가 나타나지 않고 기존 공개 가상 5개만 유지됩니다. 외부 API/지도 요청·최종 브라우저 오류 0입니다.

이번 배치에서는 전체 브라우저 QA·실물 기기·Safari/Firefox·외부 번역기·실제 경로 연결을 실행하지 않았습니다. 전체 화면 QA는 STEP 07-B-2 최종 시설 입력 후 수행합니다. 기존 Admin 전체 QA의 초기/리로드 건수만 현재 원본 건수를 따르도록 갱신했으며 이번에는 그 전체 스크립트를 재실행하지 않았습니다. 지도 필드 생략의 레거시 검사는 독립 메모리 입력에서 해당 필드를 생략해 기존 검증을 그대로 유지합니다.

공개 검색 제외는 인증 기능이 아닙니다. 원본 GitHub/개발 JSON은 공개로 읽힐 수 있으므로 비밀 정보는 넣지 않으며 개발 빌드를 고객 배포하지 않습니다. Staff의 기존 개발 경고는 전체 건수를 가상 자료로 설명하는 초기 문구여서 이번 혼합 원본의 출처 구분을 충분히 설명하지 못합니다. 이번 데이터 전용 범위에서는 UI를 수정하지 않았으며, 정확한 분류는 이 문서/추출 기준을 따릅니다. 후속 UI 검수 시 경고 문구 정리가 필요합니다.
