# STEP 5 + 6 — 직원 즐겨찾기·최근 검색 / 인쇄 안내 카드

## 직원용 화면 사용
1. 직원용 `#/staff` 화면에서 **주변 시설 안내**의 시설 상세 또는 **호텔 업무 영어 응대**의 스크립트 상세를 열고 **☆ 즐겨찾기 추가**를 누릅니다.
2. 직원 첫 화면 오른쪽 대시보드의 **빠른 안내**에서 즐겨찾기(최대 6개), 최근 검색·열람(최대 5개)을 선택하면 해당 시설·스크립트가 열립니다. 기존 타임스페이스 입점 업체 탐색 기록도 최근 열람으로 연결됩니다.
3. **전체 초기화**는 해당 브라우저의 즐겨찾기 및 최근 ID 목록만 삭제합니다. 고객명, 예약번호 및 검색어 원문은 저장하지 않습니다.
4. 브라우저별 localStorage로 저장되므로 다른 PC/브라우저와 동기화되지 않습니다. PC 정책/시크릿 모드에서 저장이 거부되면 안내 메시지를 표시하고 새로고침 후 사라질 수 있습니다.

## 인쇄 안내 카드
1. 직원용 주변 시설에서 원하는 시설의 **상세 보기**를 선택합니다.
2. **인쇄용 안내 카드 출력**을 누르면 시스템 인쇄 대화상자가 열립니다.
3. A4 한 장에 호텔 안내 카드가 보이는지 확인하고, 필요하다면 인쇄 대상을 PDF로 선택해 미리보기할 수 있습니다.
4. 카드에는 이름·주소·간단 소개·영업시간·도보 정보·네이버 지도 길찾기 QR이 있습니다. **확인된 네이버 길찾기 링크가 없으면 QR을 생성하지 않습니다.**
5. 송도 타임스페이스 길찾기 QR은 실제 건물 입구가 아닌 **인근 스타벅스 송도캐슬파크점** 목적지입니다. 카드에도 해당 주의사항을 남겼습니다.
6. 시험용 배포 상태의 카드는 **직원 사전 검수 필요**를 명시합니다. 영업시간, 출발지/도착지, 폐업 여부 등은 인쇄 전에 확인합니다.

## 기술·보안
- 별도 서버, 신규 유료 API, QR 생성 외부 요청, 방문객 개인정보 수집을 사용하지 않습니다.
- 저장 내용은 항목 종류와 ID만 포함한 제한된 JSON입니다.
- QR 이미지는 MIT 라이선스의 `qrcode-generator` 코드를 로컬에서 생성합니다. 원본 라이선스: `src/vendor/LICENSE.qrcode-generator`.
- 지도 이미지를 캡처하거나 제공하지 않으며, 길찾기 링크만 QR로 인코딩합니다.
- 인쇄물 QR의 모든 실주소를 현장 핸드폰으로 스캔하는 최종 점검은 자동화 QA와 별도로 실시해야 합니다.
