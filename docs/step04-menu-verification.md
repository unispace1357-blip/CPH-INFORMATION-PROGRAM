# STEP 4 — 음식점·카페 메뉴 예시 및 검색 키워드 검수 (2026-10-19)

## 목표와 적용 범위

- 기존 DEMO 데이터의 음식점 11개 / 카페 3개 총 14개, 네이버 지도 링크·주소·도보시간·운영시간은 변경하지 않음.
- 같은 JSON 스키마의 각 언어 `translations[lang].description`을 음식 종류 + 메뉴 예시로 통일해 직원·고객 상세 및 결과 카드에 함께 표시.
- 4개 언어 `keywords[lang]`에 일반 메뉴명, 음식 종류, 동의어를 등록. 실제 표시/검색이 같은 데이터를 사용하도록 기존 검색 서비스 유지.
- 기존 직원 영어 응대 문구 2개/매장 중 첫 문구에 메뉴 예시를 추가, 복사 기능은 영어 원문만 대상으로 함.
- 시설별 `lastVerifiedAt`은 null: 공개 웹 메뉴/프랜차이즈 일반 메뉴는 현장에서 개별 매장 판매 여부를 검증한 것이 아님. 메뉴 가격·가용 여부는 표시하지 않음.

## 검색 검수

- `맥주` 검색: 더몰트하우스 / 버거룸181 / 플레이그라운드 브루어리 / 금별맥주 포함
- `고기`: 한양·경복궁 / `갈비`: 경복궁 (한양은 확인된 한우불고기 메뉴 위주로 검색)
- `짜장면`, `중식`: 팔진향; `김밥`: 오토김밥; `쭈꾸미`: 송쭈집
- `햄버거`, `수제버거`: 버거룸/브루어리/패스트푸드 관련 매장
- `커피`, `아메리카노`: 카페 3곳, 이름 및 메뉴 데이터 동시 검색
- 단일 및 공백으로 구분된 다중 검색어를 모든 번역 필드·키워드에서 검색하며 `dining`/`cafe` 필터는 유지한다.

## 배포 정책

STEP 4는 별도 작업 브랜치/초안 PR에서 검증한다. 현장 확인 전 실제 운영용 배포와 `main` 병합은 하지 않는다. 최종 브라우저 UX·폰트·발음 보조 등은 STEP 5~6에서 검수한다.

## 2026-10-19 사용자가 제공한 네이버 메뉴 캡처 업데이트

- **한양 송도한옥마을점:** 한우양념불고기 / 한우생불고기 두 종류가 대표 메뉴임을 확인. 기존 갈비탕·보리굴비를 대표 메뉴와 검색 키워드에서 제외(판매하지 않는다고 단정하지는 않음).
- **플레이그라운드 브루어리 탭룸 송도:** 메뉴 캡처에 베트남 스타일 치킨, 통새우 수제버거와 프렌치프라이, 등파육과 칠리 카라멜 소스, 어향 가지 튀김 등이 확인됨. 대표 예시로 수제맥주 및 앞의 주요 메뉴 사용, 어향 가지 튀김은 검색어로도 등록.
- **금별맥주 송도롯데몰점:** 메뉴 캡처에 핫크리스피치킨, 불고기 피자, 토마토 해장 파스탕, 쫀득 분모자 볼스지 등이 확인됨. 기존 트러플 감자채전은 이번 메뉴 사진에서 확인되지 않아 대표 메뉴에서 제외.
- **근거 범위:** 매장 운영정보/메뉴의 사용자 제공 캡처 및 사용자 직접 확인. 화면에서 보이지 않는 메뉴·가격·품절 정보는 추측하지 않음. 캡처는 사용자가 채팅으로 제공했으며 저장소에는 재게시하지 않음.
