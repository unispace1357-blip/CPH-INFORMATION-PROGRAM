# STEP 04 Staff Guide

## 구현 범위와 데이터

`/staff`에서 한국어·영어 로컬 검색, 카테고리 필터, 결과 카드 선택, 시설 상세 안내, 등록된 영어 문구 표시·복사를 구현했습니다. 직원용 기능만 연결했으며 Guest의 STEP 03 기본 화면은 유지합니다. 데이터는 `src/data/index.ts`의 `facilityDataset`만 사용합니다. 별도 시설 목록, 외부 API, 서버 DB, 새 라이브러리는 추가하지 않았습니다.

현재 JSON은 `demo` 상태의 가상 시설 6개이며 그중 공개 시설 5개가 검색됩니다. 상단에 가상 데이터 경고를 표시합니다. 데이터와 `dataStatus`를 변경하지 않았고 실제 영업시간·주소·휴무일·도보시간을 임의로 만들지 않았습니다. 이 자료는 실제 고객 안내에 사용할 수 없습니다.

공통 모듈을 비동기로 가져와 검증 성공 후 표시합니다. 로딩 중에는 입력·필터를 비활성화합니다. 공통 데이터 검증 또는 모듈 로딩이 실패하면 오류 안내와 새로고침 버튼을 표시하고 대체 시설 목록을 만들지 않습니다. Guest는 이 데이터를 불러오지 않으므로 Staff 데이터 오류가 있어도 기본 화면을 표시할 수 있습니다.

## 검색 알고리즘

`src/services/facilitySearch.ts`가 UI와 분리된 검색을 수행합니다.

검색 필드:

- `translations.ko.name`, `translations.en.name`
- `keywords.ko`, `keywords.en`
- `translations.ko.address`, `translations.en.address`

NFC 유니코드 정규화, 앞뒤 공백 제거, 소문자 변환 후 문자열 `includes`로 비교합니다. 특수문자를 정규식으로 해석하지 않습니다. 빈 검색어는 공개 시설 전체를 반환합니다. 결과는 원본 JSON 순서이며 입력 배열을 변경하지 않습니다. 검색어 변경 시 즉시 갱신하고 결과 개수를 표시합니다.

중국어·일본어 이름과 키워드, 설명, 응대 문구, 카테고리 표시명은 검색 대상이 아닙니다. `사우나`라는 검색어만으로 `sauna_spa` 시설을 자동 포함하지 않습니다. 주소도 같은 로컬 부분 문자열 검색 규칙으로 지원합니다.

## 카테고리와 선택

원본 10개 카테고리와 `전체` 버튼을 사용합니다. 최초 선택은 전체이며 검색어와 카테고리는 AND 조건입니다. 전체 버튼은 카테고리 제한만 해제하고, 검색어 지우기는 검색어만 초기화합니다.

비공개 시설은 이름·키워드·카테고리와 무관하게 결과에서 제외합니다. 상세 선택도 현재 공개 검색 결과 안에서만 해석합니다. 검색 조건 변경으로 선택 시설이 제외되면 선택 ID를 해제하고 상세·영어 문구·복사 피드백을 초기화합니다. 이후 조건을 되돌려도 자동 재선택하지 않습니다.

카드 내부의 독립된 상세 보기 버튼을 사용하므로 중첩 버튼이 없습니다. 선택 카드는 배경·테두리와 `aria-pressed`로 구분합니다. 좁은 화면에서 새 시설을 선택하면 상세 제목으로 포커스와 스크롤을 이동합니다. 검색·선택 과정에서 페이지 경로를 바꾸지 않습니다.

## 결과와 상세 정보

공개 시설이 없으면 “등록된 시설 정보가 없습니다.”, 검색 조건에 맞는 시설이 없으면 “검색 결과가 없습니다. 다른 검색어 또는 카테고리를 선택해 주세요.”를 표시합니다.

결과 카드에는 한·영 시설명, 카테고리, 영업시간, 도보시간과 상세 버튼을 표시합니다. 상세에는 한국어 이름·설명·주소·영업시간·휴무일·도보시간·이동 안내·참고 사항·확인일과 영어 이름·영어 이동 안내를 표시합니다.

| 항목 | 미확인/표시 규칙 |
| --- | --- |
| 주소 | 주소 미확인 |
| 영업시간 | 영업시간 미확인 |
| 휴무일 | 휴무일 미확인 |
| 이동 안내 | 이동 안내 미확인 |
| 영어 이동 안내 | 영어 이동 안내 미확인 |
| 참고 사항 | 등록된 참고 사항 없음 |
| walkingMinutes = 5 | 약 도보 5분 |
| walkingMinutes = null 또는 유효한 숫자가 아님 | 도보시간 미확인 |
| lastVerifiedAt = null | 정보 확인 전 |
| 확인일 있음 | 최종 확인: YYYY-MM-DD |

시간을 계산·추정하거나 숫자 문자열을 도보시간으로 변환하지 않습니다. 등록된 확인일이 현재 영업 상태를 보장한다고 표현하지 않으며 “영업 중”, “지금 방문 가능”을 자동 판단하지 않습니다.

## 영어 문구와 복사

선택 시설의 `englishPhrases`만 순서대로 표시합니다. 자동 번역이나 영어 문장 생성은 하지 않습니다. 배열이 비어 있으면 등록되지 않았다는 안내와 비활성 복사 버튼을 표시합니다. 문구가 1개이면 개별 복사, 여러 개이면 개별 복사와 전체 문구 복사를 제공합니다. 전체 복사는 등록 순서를 유지하고 줄바꿈으로 연결합니다.

`src/services/clipboard.ts`는 주입 가능한 `ClipboardWriter`를 사용합니다. 실제 화면에서는 보안 컨텍스트의 `navigator.clipboard.writeText()`로 복사합니다. HTTPS 또는 localhost와 브라우저 권한이 필요합니다. API 미지원, 권한 거부와 기타 실패를 처리하며 앱을 멈추지 않습니다.

복사 중에는 중복 요청을 막고, 성공 시 “복사 완료”, 실패 시 “복사에 실패했습니다. 문구를 직접 선택해 복사해 주세요.”를 표시합니다. `role=status`, `aria-live=polite`로 안내하며 실패해도 문구 텍스트를 직접 선택할 수 있습니다. 다른 시설을 선택하거나 선택이 해제되면 이전 복사 상태를 유지하지 않습니다.

클립보드 미지원과 권한 거부는 브라우저 API를 대체하여 모의 검증했습니다. 오류 안내와 텍스트 직접 선택이 정상입니다. 검증 불가능한 시설 객체를 주입하면 목록 대신 오류를 표시하며 Guest는 정상 유지됩니다. 빈 공개 목록은 별도 빈 상태를 표시합니다. 가로 넘침, 텍스트 잘림, JavaScript·콘솔·HTTP 오류, 외부 리소스/API 요청은 없었습니다.

기존 `/`, `/guest`, `/staff`, 404와 favicon도 기존 QA 방식으로 320·375·390·430·768·1280px에서 확인했습니다. 실제 직원 PC(1280px), 모바일(390px) 실행 캡처를 제공했습니다.

### 브라우저 재검증

기존 별도 QA 환경의 Playwright와 시스템 Chromium을 재사용하며 앱 의존성은 변경하지 않았습니다.

```bash
# 터미널 1
npm run dev -- --host 0.0.0.0 --port 5174 --strictPort

# 터미널 2: 이 클라우드 QA 환경
NODE_PATH=/tmp/cph-browser-check/node_modules \
CPH_UI_ARTIFACT_DIR=/workspace/exports/step04 \
npm run test:staff-ui

NODE_PATH=/tmp/cph-browser-check/node_modules \
CPH_UI_ARTIFACT_DIR=/workspace/exports/step04-regression \
npm run test:ui
```

다른 환경에서는 별도 Playwright 경로와 Chromium이 필요합니다. `CPH_CHROMIUM_PATH`, `CPH_UI_BASE_URL`, `CPH_UI_ARTIFACT_DIR`로 경로를 지정할 수 있습니다. QA 도구가 없으면 브라우저 검증을 수행할 수 없으며 PASS로 간주하지 않습니다.

## 알려진 제한과 다음 단계

현재 검증 범위에서 미해결 코드 오류는 발견하지 않았습니다. 실물 휴대전화, Safari/Firefox, 스크린리더, 실제 운영 환경의 클립보드 권한 UI와 정적 호스팅 배포는 미검증입니다. 데이터는 계속 가상 정보이며 운영용 배포는 차단됩니다.

직원 경로는 인증 기능이 아니므로 비밀 정보나 고객 개인정보를 넣지 않습니다. 비공개 플래그는 표시 제어이며 정적 번들에서 파일을 직접 읽는 것을 막는 기능은 아닙니다.

고객용 실제 다국어 전환·검색·상세는 STEP 05, 관리자 기능은 STEP 06에서 검수 후 진행합니다. 이번 단계에서는 실제 호텔·주변 시설 정보, AI, 번역·지도 API, 영업 상태 계산, 계정, QR 또는 실제 배포를 구현하지 않았습니다.
