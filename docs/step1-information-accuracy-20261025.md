# CPH 1차 정보 정확성 변경 (2026-10-25)

사용자 제공 프론트 운영 정보를 근거로 1·4·5·6·9·10·11번을 수정한다. 기존 Step07A 원본 번역·SHA256 및 Step2 음식 배달 안내 수정 이력은 변경하지 않고, `docs/reference/step1-info-accuracy-20261025.json`에 새 수정 사항을 기록한다.

- 직원 화면에서 검수 전·draft 배지만 숨겼다. 모든 스크립트의 `reviewStatus: draft`, `lastVerifiedAt: null`은 그대로 유지한다. 검수 완료나 정식 운영 승인을 뜻하지 않는다.
- 고객용 체크인 안내에서 신분증이나 보증금을 일률적으로 요구하지 않는다는 H05 문구를 4개 언어 모두 삭제했다. 직원용 안내는 현금 보증금, 보증용 카드, 키오스크 신분증을 구분하고 신분증 미소지 시 프론트 문의로 유도한다.
- 성인 조식 H10과 직원용 응대의 요금을 35,000원으로 반영했다. 어린이 조식 19,000원은 그대로 둔다.
- 6·10·16층 전자레인지, 수저·젓가락·나이프·와인잔 제공 안내를 추가하고 침대 옆 조명 스위치를 4개 언어 및 직원용에 반영했다.
- 방연창(smoke ventilation window) 직원용 응대 문구를 추가했다. 실제 개폐 방식과 고객 조작 가능 여부는 최종 현장 확인이 필요하므로 직접 조작을 유도하는 표현은 사용하지 않는다.
- 6777번 성인 요금 8,000원을 고객 4개 언어와 직원용에 추가했다. 참고 근거: 송도컨벤시아 공식 안내 https://songdoconvensia.visitincheon.or.kr/page/nav-from-airport2.do. 이전 호텔 인쇄 안내문의 센트럴파크 정류장 출발 예정 시각 12개는 유지한다. 실시간 운행 정보가 아니므로 탑승 전 최신 운행정보 확인 필요.
- 호텔 `lastVerifiedAt`은 실제 최종 검수 이전이므로 변경하지 않았다. 데이터는 계속 DEMO다.
