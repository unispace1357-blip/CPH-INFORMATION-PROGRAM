# CPH 송도 타임스페이스 분류 및 길찾기 보완 (2026-10-25)

## 변경 사항
- 타임스페이스 원본 시설 한 건(`songdo-timespace-complex`)은 `shopping`이 기본 카테고리이며, `additionalCategories: ['dining']`으로 음식점·주점에도 표시한다.
- 시설 목록은 총 27개로 동일하다. 카테고리 버튼과 고객·직원 검색이 추가 카테고리를 인식하며, 상세 카드에는 두 카테고리를 병기한다.
- 사용자가 제공한 출발 호텔 → **스타벅스 송도캐슬파크점** 네이버 도보 길찾기 링크를 변경 없이 등록한다. 목적지 Naver PLACE_POI = `1617698245`이고 호텔 출발 PLACE_POI = `19398065`이다.
- **주의:** 스타벅스 송도캐슬파크점은 타임스페이스(하모니로 158)와 건물이 다르다. 손님에게는 '근처의 기준점'이라고 안내하고 스타벅스 도착 후 타임스페이스까지 추가로 이동하도록 한국어·영어·중국어·일본어와 직원 영어문구에 명시한다.
- 이전 길찾기는 같은 건물의 별온누리약국을 목적지로 사용했으며, 그때의 참고 도보시간 17분은 새 스타벅스 경로와 무관하므로 `walkingMinutes: null`로 변경한다. 실제 시간은 임의 추정하지 않는다.
- 실제 영업시간·입점 상태 및 새로운 스타벅스 경로의 인근 접근성이 변동할 수 있으므로 최종 현장 확인은 유지한다. `demo` 상태 및 `lastVerifiedAt: null`은 변경하지 않는다.

## 검수
- 추가 카테고리 중복, 데이터 스키마·어드민 편집 및 검색 단위 테스트
- 음식점/쇼핑 필터에 시설 단 한 건만 표시되는지 고객·직원 실제 브라우저 QA
- 네이버 길찾기 출발/도착 지점 ID 및 4개국어 위치 주의문구 검사
- GitHub Pages는 DEMO로 유지하며 사용자 QR 주소는 변경하지 않는다.
