# STEP 6 — 현장 운영정보 추가 확인 (2026-10-19)

이 문서는 채팅에서 사용자가 제공한 네이버 지도 영업시간·메뉴 캡처 5장 및 금별맥주 직접 확인 정보를 토대로 작성한 **후속 QA 변경 기록**이다. 사진을 저장소에 재업로드하지 않으며, 데이터셋의 `dataStatus=demo` 및 `lastVerifiedAt=null`을 유지한다. 따라서 실제 매장 내부에서 최종 승인한 기록으로 해석하지 않는다.

## 1. 최종 영업시간

| 매장 | 한국어 표준 정보 | 마지막 주문 | 확인 방법 |
| --- | --- | --- | --- |
| 금별맥주 송도롯데몰점 | **매일 17:00~익일 01:00** | **매일 00:00** | 사용자 직접 확인한 운영시간 (사진 5는 메뉴 화면이며 영업시간 증빙은 아님); 추석 등 명절 임시휴무 가능 |
| 한양 송도한옥마을점 | **월~금 11:30~22:00**, **토·일 11:00~22:00** | 매일 **21:30** | 사진 1, 네이버 지도 영업시간 패널. 평일에만 **15:00~17:00** 브레이크타임 표시 |
| 플레이그라운드 브루어리 탭룸 송도 | **월~금 15:00~24:00 / 토 12:00~24:00 / 일 12:00~22:00** | 월~토 **23:00**, 일 **21:00** | 사진 2, 네이버 지도 영업시간 패널 |

임시·특별 휴무는 실제 매장 확인을 우선하며 네이버 지도의 **예약 탭/예약 표시가 곧 실시간 예약 가능성을 보장하지는 않는다.** 이번 앱은 예약 기능을 추가하지 않았다.

## 2. 대표 메뉴·키워드

| 매장 | 네이버 메뉴에서 확인한 음식/사용자 강조 메뉴 | 앱에 반영한 내용 |
| --- | --- | --- |
| 한양 | 사용자가 직접 **한우불고기: 양념불고기, 생불고기**를 대표 메뉴로 지정. 사진 4 네이버 메뉴에는 한우 정식/양념 메뉴 표시 | 대표 메뉴 2종으로 좁힘. 이전 갈비탕·보리굴비정식은 해당 자료로 확정할 수 없어 대표 메뉴/검색어에서 제거(판매하지 않는다는 결론 아님) |
| 플레이그라운드 | 사진 3에서 **베트남 스타일 치킨, 통새우 수제버거와 프렌치프라이, 등파육과 칠리 카라멜 소스, 어향 가지 튀김** 확인 | 수제맥주 및 앞의 주요 음식 3개를 4언어 대표 예시로, 어향 가지 튀김을 한국어 검색어로 반영 |
| 금별맥주 | 사진 5에서 **핫크리스피치킨, 불고기 피자, 토마토 해장 파스탕, 쫀득 분모자 볼스지** 확인 | 맥주 + 앞의 음식 3개를 4언어 대표 예시로 변경, 분모자 메뉴 검색어 추가. 기존 트러플 감자채전은 이번 사진에서 확인되지 않아 대표 목록에서 제외 |

음식 이름은 캡처의 **표기명**을 우선한다. 한국어 메뉴명은 자동 번역으로 바꾸지 않고, 영어·중국어·일본어는 고객에게 설명하기 쉬운 의미 중심으로 번역한다. 번역에 어려운 고유 메뉴(예: *토마토 해장 파스탕*)는 원어명과 다소 다른 설명문을 쓸 수 있다. 원어민 최종 교정과 실판매/품절 확인은 별개로 남긴다.

## 3. 변경 범위와 데이터 무결성

- `src/data/facilities.json`의 세 시설 `translations.[ko,en,zh-CN,ja].openingHours`, `description`, `keywords`를 일괄 수정.
- 직원이 복사하는 `englishPhrases` 및 화면의 `englishPhraseMeanings`를 새 시간표·메뉴와 동기화.
- 호텔 기본 원고, 다른 시설 23곳의 운영시간, 기존 네이버 지도 경로/도보시간, 금연·배달 규정에는 변경 없음.
- 사용자 관찰에 기반한 상세 정정이므로 기존 미검수 필드 `lastVerifiedAt:null`, 전체 `demo/draft` 및 운영 배포 차단을 그대로 유지.
- `scripts/step06-field-confirmation.test.ts` 회귀 테스트로 시간/마감·대표 음식·검색 키워드·영문 응대 일관성 재검증.

## 4. 남은 실사용 확인

- 명절/휴무 일정, 실제 재고·메뉴 품절, 네이버 예약 이용 가능성은 실시간으로 보장하지 않음.
- 현장 담당자가 한국어/영어/중국어/일본어에서 **시간·요일·마감 주문이 잘 읽히는지** 최종 확인.
- 실제 휴대전화에서 출발지 지정 네이버 링크가 정확히 열리는지 확인.
