# 송도 관광 사진 3종 — 출처·라이선스·사용방법

## 사용 범위

고객 관광 개념도의 **번호 1·2·3은 유지**하고, 장소를 선택하면 상세 설명 카드에 해당 명소의 실제 사진 1장만 표시한다. 4·5·6번은 사진을 임의로 추가하지 않는다. 원본 지도 좌표, 이동 링크, 시설 운영안내 및 경고는 변경하지 않는다.

## 사진 사용 출처 — 인천경제자유구역청(IFEZ)

세 게시물 모두 게시물 하단에 **"본 게시물은 공공누리 제1유형: [출처표시] 조건에 따라 이용이 가능합니다."**라고 명시되어 있다. 각각 출처 링크를 사용자 화면의 사진 아래에 표시한다. 촬영 시점의 역사적 사진으로서 현재와 달라질 수 있다고 안내한다.

- 저작물 출처(화면 표기): **인천경제자유구역청(IFEZ)**.
- 이용허락: 공공누리 제1유형(출처표시). 원본 사진의 개별 게시물 이용 조건을 다시 확인한 뒤 사용한다.
- 기술 구현: 외부 IFEZ 사이트의 공개 이미지 주소를 이용하며, 사진이 차단되거나 만료되면 **사진 없는 안내와 공식 원문 링크**를 보여준다.
- 위 파일은 프로젝트에 별도 저장된 사진이 **아니다**. 장기 운영용으로는 허용 조건을 재확인한 뒤 직접 내려받아 용량을 최적화(WebP)해 프로젝트에 넣는 것을 권장한다.
- 출처 페이지가 공공누리 제1유형을 표시하더라도 일부 인물·상표·건축물 등 제3자 권리가 있을 수 있으므로 향후 사진 교체나 인쇄물 제작 시 별도 확인한다.

## 2026-10-20 사진 프레이밍 개선 — 검토 브랜치

- G타워 기존 3882 사진은 실제 렌더링에서 하늘이 대부분을 차지하고 건물이 작게 나타나 부적합했다. 새로 선정한 IFEZ **3875 사진**(같은 2015-04-01 자료)은 건물 전체가 사진 중심에 보이는 구도를 원본에서 육안 확인했다. 2025년 2243~2245 고해상도 원본도 검토했지만 크기가 약 12MB 이상이고 구도를 직접 확인하지 못해 채택하지 않았다.
- 한옥마을은 IFEZ 2015-01-05 **0316 사진**(한옥 기와지붕과 고층 건물의 대비)을 선택했다. 원본을 확인했다. 다만 한옥 전경보다는 지붕 중심 구도라는 한계가 있어 추후 더 넓은 전경으로 바꿀 수 있다.
- 해돋이공원은 IFEZ 2022-05-02 **6751 사진**을 후보로 연결했다. 게시물은 해돋이공원 장미정원·고래분수·꽃길을 소개하지만 개별 원본이 크기 제한으로 미리 보이지 않아 **고래 조형물 사진이라고 단정하지 않는다**. 최종 사용자 검수 필요.
- 미추홀공원은 IFEZ 2019-04-19 **9723 사진**(정자·연못 반영)을 원본 검색 미리보기에서 확인해 채택했다.
- 출처: [G타워](https://www.ifez.go.kr/promote/pst/view.do?pst_id=scene_photo&pst_sn=664965), [한옥마을](https://www.ifez.go.kr/promote/pst/view.do?pst_id=scene_photo&pst_sn=664955), [해돋이공원](https://www.ifez.go.kr/promote/pst/view.do?pst_id=scene_photo&pst_sn=665089), [미추홀공원](https://www.ifez.go.kr/promote/pst/view.do?pst_id=scene_photo&pst_sn=665035). 각 게시물에 공공누리 제1유형(출처표시) 명시.
- 사진 컨테이너를 강제 16:10 고정에서 원본 가로세로 비율 우선으로 변경했다. 장면 일부를 자르는 `object-fit: cover`는 사용하지 않는다. 화면별 최대 높이만 제한하고 `contain`을 유지한다.
- 출처 링크와 역사적 사진 안내, URL 사용 불능 시 대체안내를 유지한다. 원본을 내려받는 대신 외부 서버를 참조하므로 로딩 속도 및 운영 지속성은 추후 확인이 필요하다.
- 4개 언어 alt·저작권 표시·실제 이미지 로딩·비율 왜곡 방지·기존 네이버 안내를 QA 대상으로 추가한다. **공개 배포 전 리뷰 브랜치 검토 대상**이다.
