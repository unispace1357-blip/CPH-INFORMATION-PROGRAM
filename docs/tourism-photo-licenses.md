# 송도 관광 사진 3종 — 출처·라이선스·사용방법

## 사용 범위

고객 관광 개념도의 **번호 1·2·3은 유지**하고, 장소를 선택하면 상세 설명 카드에 해당 명소의 실제 사진 1장만 표시한다. 4·5·6번은 사진을 임의로 추가하지 않는다. 원본 지도 좌표, 이동 링크, 시설 운영안내 및 경고는 변경하지 않는다.

## 사진 사용 출처 — 인천경제자유구역청(IFEZ)

세 게시물 모두 게시물 하단에 **"본 게시물은 공공누리 제1유형: [출처표시] 조건에 따라 이용이 가능합니다."**라고 명시되어 있다. 각각 출처 링크를 사용자 화면의 사진 아래에 표시한다. 촬영 시점의 역사적 사진으로서 현재와 달라질 수 있다고 안내한다.

| 관광지 | 촬영일 | 게시물 원문 | 선택한 사진 |
|---|---|---|---|
| 1. 송도 센트럴파크 | 2024-09-23 | https://www.ifez.go.kr/promote/pst/view.do?pst_id=scene_photo&pst_sn=667087 | (240923)송도국제도시(4042)-원본.jpg |
| 2. 트라이볼 | 2009-08-06 | https://www.ifez.go.kr/promote/pst/view.do?pst_id=scene_photo&pst_sn=249272 | (090806)송도국제도시(225095)-원본.jpg |
| 3. G타워 | 2015-04-01 | https://www.ifez.go.kr/promote/pst/view.do?pst_id=scene_photo&pst_sn=664965 | (150401)IFEZ 송도국제도시(3882)-원본.JPG |

- 저작물 출처(화면 표기): **인천경제자유구역청(IFEZ)**.
- 이용허락: 공공누리 제1유형(출처표시). 원본 사진의 개별 게시물 이용 조건을 다시 확인한 뒤 사용한다.
- 기술 구현: 외부 IFEZ 사이트의 공개 이미지 주소를 이용하며, 사진이 차단되거나 만료되면 **사진 없는 안내와 공식 원문 링크**를 보여준다.
- 위 파일은 프로젝트에 별도 저장된 사진이 **아니다**. 장기 운영용으로는 허용 조건을 재확인한 뒤 직접 내려받아 용량을 최적화(WebP)해 프로젝트에 넣는 것을 권장한다.
- 출처 페이지가 공공누리 제1유형을 표시하더라도 일부 인물·상표·건축물 등 제3자 권리가 있을 수 있으므로 향후 사진 교체나 인쇄물 제작 시 별도 확인한다.
