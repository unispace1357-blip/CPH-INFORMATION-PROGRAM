# CPH 3차: 송도 타임스페이스 대표 외식·길찾기 안내

작성일: 2026-10-25 · 프로그램 상태: DEMO · 실제 호텔 운영 최종 승인 아님.

## 설계 결정

- **시설 1개만 등록:** `songdo-timespace-complex` (`shopping`). 식당마다 독립 카드와 영업시간을 대량 생성하지 않는다.
- **4개 언어:** 카레, 라멘, 돼지고기 구이, 즉석떡볶이 대표 메뉴와 이름 4개(도라보울·오바케·숯멍·보니보니). 영업 여부/메뉴/위치는 방문 전 재확인하도록 안내.
- **검색:** 타임스페이스, 타임 스페이스, 스프카레, 라멘, 고기, 떡볶이 및 영어·중국어·일본어 검색어에서 하나의 통합 안내 카드 노출. 고객·직원용 동일 JSON 유지. 두 화면의 카드 요약에도 메뉴 범주 표시.
- **길찾기:** `naverMapUrl`에 없는 좌표/장소ID를 임의 생성하지 않고, 기존의 검토된 출발 호텔 → **송도 타임스페이스 A동 별온누리약국** 도보 네이버 링크를 재사용. 목적지가 타임스페이스 중심이 아니라 약국임을 네 언어 directions/notes 및 직원 영어 응대로 명시. A·B·C·D동 중 실제 식당 동을 방문자가 현장 확인.
- **도보 시간:** 같은 A동 위치로 기존 등록된 별온누리약국의 참고치(17분) 재사용. 실시간 소요시간이나 최적 경로는 보장하지 않음.
- **전체 사업자 및 임대 정보 미등록:** 시설 전체 운영시간을 임의로 지정하지 않는다.
- **기존 시설 26개 보존 → 총 27개**; 11개 음식점, 3개 카페, 기존 공항버스·관광·금연·체크인 안내는 변경하지 않는다.
